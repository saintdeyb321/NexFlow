## Selección de la primera corrección

Propuesta para el propietario/auditor: D02–D04 para la primera entrega informativa del plan; decidir expresamente si se adelanta el guard D01 por riesgo de crear un borrador equivocado. D05 requiere política de consentimiento acordada. D06–D07 son la capacidad de gestión posterior, no un añadido oculto al cambio de tono. D08–D10 no justifican reabrir durabilidad ya correcta sin medición.

Fuera de alcance: agente autónomo que decide transacciones; mantener citas históricas en Redis; RAG/embeddings por intuición; migraciones/TTL/limpieza de producción; cambiar Evolution/n8n/arquitectura; tratar una tasa sintética aprobada como calidad real. No se propone aumentar tokens para compensar una selección de fuente o permiso incorrectos.

**Para cada decisión aprobada:** parche pequeño, una reproducción mínima del defecto y regresiones de seguridad relacionadas; revisión del texto completo y estado antes/después en simulación supervisada. Métricas y umbrales comerciales se acordarán después de establecer línea base. Este diagnóstico no autoriza ejecutar el Prompt 2.
